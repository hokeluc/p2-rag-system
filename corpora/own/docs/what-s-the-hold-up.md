# What's The Hold Up

This rules of this competition are similar to the Pressure Cooker.

1. Each contestant stands on a platform a short distance from a plaque.
2. Using a long and flexible pole, contestants must hold an object in place against the plaque using while remaining on their platform. Some iterations impose restrictions on number the of hands used and/or foot placement; these restrictions are often introduced as the competition progresses.
3. If the object falls off the plaque or the contestant steps off their platform, they are eliminated from the challenge. Some iterations have restrictions on the number of hand The last person remaining wins the competition.
